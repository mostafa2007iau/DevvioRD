Mouse mode

Drag anywhere to move the pointer, tap to click, tap twice quickly to double-click, two-finger drag to scroll. The wheel works directly.

Touch mode

Your finger is the pointer: taps land exactly where you press. Two-finger drag scrolls. Use touch mode for anything with big targets, mouse mode for precision.

Clipboard

📋↑ sends this device's clipboard to the host, 📋↓ copies the host clipboard here. Text is synced both ways the moment either side changes.
