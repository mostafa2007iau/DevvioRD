# راهنمای کاربر DevvioRD

## ۱. آماده‌سازی سرور

روی کامپیوتری که می‌خواهید کنترل شود:

```bash
chmod +x devviord
./devviord --token 1234
```

خروجی چیزی شبیه این است:

```
  Host      : workstation (linux/amd64)
  Backends  : capture=ffmpeg-x11grab  input=x11:/usr/bin/xdotool  clipboard=x11:xclip
  Streaming : 20 fps, JPEG q70
  Token     : 1234

  Connect from the DevvioRD Android app or a browser:
    http://192.168.1.10:5900
    http://localhost:5900   (this machine)

  Scan to pair:
    █▀▀▀▀▀█ ▄█ ▄▄ ...
```

آدرس `192.168.x.x:5900` را در اپ وارد کنید، یا QR را با اپ اسکن کنید.

> اگر روی سرور بدون نمایشگر اجرا می‌کنید، DevvioRD یک **دسکتاپ مجازی داخلی**
> می‌سازد تا اپ بلافاصله قابل تست باشد (`--mode app`).

## ۲. اتصال از اپ اندروید

1. اپ DevvioRD را نصب و باز کنید.
2. آدرس سرور را وارد کنید (`192.168.1.10:5900` یا فقط IP).
3. توکن را وارد کنید.
4. حالت کنترل را انتخاب کنید (لمسی یا موس) و **اتصال** را بزنید.

سرورهای قبلی زیر «آدرس‌های اخیر» ذخیره می‌شوند؛ یک ضربه برای اتصال کافی است.

## ۳. استفاده

| کار | روش |
| --- | --- |
| کلیک | در حالت لمسی: لمس نقطه · در حالت موس: ضربه (کلیک روی نشانگر) |
| حرکت موس | حالت موس: کشیدن انگشت روی صفحه |
| دابل‌کلیک | دو ضربه سریع |
| درگ | لمس و کشیدن (حالت لمسی) |
| اسکرول | دو انگشت بالا/پایین |
| کلیک راست | منو ← `Ctrl` (یا کلید ContextMenu در کلاینت وب) |
| کیبورد | دکمه ⌨ (یا آیکن صفحه‌کلید در نوار پایین) |
| تغییر حالت | دکمه TOUCH/MOUSE در نوار بالا |
| آمار | منو ← آمار (fps، RTT، حجم دریافتی) |
| کیفیت | منو ← کیفیت تصویر (۴ پروفایل آماده) |

## ۴. کیبورد و تایپ فارسی

دکمه ⌨ را بزنید، صفحه‌کلید اندروید باز می‌شود. هر چیزی که تایپ کنید — فارسی،
عربی، چینی، ایموجی — به صورت متن یونیکد به سرور می‌رسد؛ نه به صورت کد کلید.
بنابراین:

- تایپ فارسی در سرور دقیقاً همان چیزی است که روی گوشی می‌بینید.
- Backspace کار می‌کند، حتی برای حذف حرف‌های فارسی و ایموجی.
- Enter خط جدید/تأیید می‌فرستد.
- کیبورد بلوتوث یا USB هم پشتیبانی می‌شود (Ctrl+C، Ctrl+V، Alt+Tab، F1..F12).

## ۵. کلیپ‌بورد

| جهت | کار |
| --- | --- |
| گوشی → سرور | متن را در گوشی کپی کنید، سپس در اپ دکمه **⎘** (نوار پایین) یا منو ← «منتقل کردن کلیپ‌بورد گوشی → سرور» |
| سرور → گوشی | دکمه **⤓** یا منو ← «کپی کلیپ‌بورد سرور → گوشی» |

اگر روی سرور چیزی کپی شود (در خود دسکتاپ)، اپ خودکار آن را در کلیپ‌بورد گوشی
قرار می‌دهد و پیام «کلیپ‌بورد سرور کپی شد ✓» نشان می‌دهد.

## ۶. انتقال فایل

دکمه **⇄** صفحه فایل‌ها را باز می‌کند:

- **آپلود به سرور**: «↑ آپلود به سرور» → انتخاب فایل → در پوشه جاری سرور ذخیره می‌شود.
  فایل‌های بزرگ در چانک‌های ۱ مگابایتی ارسال می‌شوند؛ اگر اتصال قطع شود، از همان
  جا ادامه می‌یابد.
- **دانلود به گوشی**: روی فایل در لیست بزنید → در `Downloads/DevvioRD` ذخیره می‌شود.
- **مدیریت**: نگه‌داشتن انگشت روی فایل → تغییر نام / حذف. دکمه «پوشه جدید» هم موجود است.

پوشه سرور با `--files` تعیین می‌شود (پیش‌فرض `~/DevvioRD/Downloads`).

## ۷. رفع اشکال

| مشکل | علت / راه‌حل |
| --- | --- |
| «اتصال برقرار نشد» | IP درست است؟ گوشی و کامپیوتر در یک شبکه‌اند؟ فایروال پورت 5900 را باز کرده؟ |
| «unauthorized» یا قطع فوری | توکن اشتباه است؛ همان توکنی را وارد کنید که سرور چاپ کرده |
| تصویر می‌آید ولی لمس کار نمی‌کند | روی سرور `xdotool` نصب نیست (`apt install xdotool`) — با `--list-backends` بررسی کنید |
| تصویر سیاه/نمی‌آید | `ffmpeg` نصب نیست یا `DISPLAY` اشتباه است؛ یا با `--mode app` تست کنید |
| کلیپ‌بورد همگام نمی‌شود | `xclip` (یا `wl-clipboard` روی Wayland) نصب نیست |
| کندی روی اینترنت | کیفیت را کم کنید (منو ← کیفیت) یا سرور را با `--scale 0.7 --fps 12` اجرا کنید |

## ۸. امنیت در اینترنت

1. پورت را روی روتر به کامپیوتر هدایت کنید (Port Forwarding).
2. حتماً `--token` با مقدار طولانی تصادفی بگذارید (`./devviord --gen-token`).
3. بهتر است سرور را پشت nginx با TLS بگذارید و از `wss://` استفاده کنید.
4. `--pair-public` را فقط در شبکه خانگی استفاده کنید (توکن را داخل QR می‌گذارد).

نمونه پیکربندی nginx:

```nginx
server {
    listen 443 ssl;
    server_name rd.example.com;
    ssl_certificate     /etc/letsencrypt/live/rd.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/rd.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:5900;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }
}
```
